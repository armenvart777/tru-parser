# Парсер каталога ТСР

Сопоставляет строки из CSV с каталогом технических средств реабилитации СФР по модели и производителю. С полных карточек собирает сведения о товаре, включая коды и данные регистрационного удостоверения. Для дополнительного поиска и проверки РУ в проекте есть этапы Росздравнадзора.

## Запуск

Установите зависимости и положите в рабочую папку свой `spreadsheet.csv` в UTF-8. Заголовки, которые читает парсер, перечислены ниже.

```text
Товар,Производитель,Модель,Код ТСР,Номер РУ
```

```bash
python -m pip install -r requirements.txt
python main.py --run --no-download
```

Команда запрашивает каталог и карточки СФР, сохраняет промежуточные данные в `progress.json` и записывает результат в `tru_data.csv`. Флаг `--no-download` оставляет ваш входной CSV. Отдельный режим `--full --no-download` добавляет этапы проверки РУ и формирование XLSX.

Параметры и список команд см. в `python main.py --help`. Модуль записи результатов в Google Sheets в публичной версии содержит только интерфейс. Файлы CSV и XLSX формируются локально.
